# Virial
---

Virial is a file manager for Linux desktops.
It helps you browse and organize files from one compact interface.
Navigate folders and mounted locations with the sidebar and breadcrumbs.
Search across accessible locations without an external index.
Group frequently used folders into workspaces.
Preview supported images and text files before opening them.
Select, move, copy, rename, and manage files from the browser.
Keyboard shortcuts support navigation and common actions.
Virial is built in Rust with GPUI.

## Quickstart

### Install

```sh
./install.sh
```

### Run from source

```sh
cargo run --release
```
