# Virial GPUI

Virial is a Linux file manager for browsing and organizing files.

## Features

- Browse local folders, mounted drives, and recent files.
- Search across locations and preview supported images and text files.
- Group folders into persistent workspaces.
- Select, copy, move, rename, and trash files.
